# Security Policy

The security policy for all NATS projects is in the
[nats-general](https://github.com/nats-io/nats-general) repository and the
current version can be found at:
<https://github.com/nats-io/nats-general/blob/main/SECURITY.md>.

A history of advisories can be found on <https://advisories.nats.io/> and our
Advisory Policy at <https://advisories.nats.io/advisory-policy> covers some
scenarios of things which are or are not security issues.

For the nats-server specifically, please use the
[GitHub Security Advisory Reporting](https://github.com/nats-io/nats-server/security/advisories/new)
flow.

Thank you.  Good luck, and stay safe.
